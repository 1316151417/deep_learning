3 线性模型：特征加权求和

模型定义

ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b

等价于向量的内积加偏置：

ŷ = wTx + b

权重的含义：特征重要程度

以房价预测为例：

特征权重含义
面积越大越贵 (w > 0)
地段评分越好越贵 (w > 0)
房龄越老越便宜 (w < 0)

模型本质上是在学习"世界的规律"——每个特征对最终输出有多大影响。

🪜 本质

输入 × 权重。权重就是模型对世界的"理解"。学习的过程，就是让权重从随机值逐渐变成能反映真实规律的值。

4 损失函数：机器如何知道"错了"？

模型一开始权重随机、输出乱猜。例如：

  • 真实房价：500 万
  • 预测房价：120 万

机器怎么知道错了？

靠——损失函数。

ℓ(ŷ, y) = ½(ŷ − y)²

🎯 核心思想

预测越离谱，损失越大。模型的目标就是让这个损失值越来越小。

整个训练过程可以概括为一句话：

预测 → 算损失 → 调参数 → 损失变小 ↻

5 为什么用平方损失，而不是绝对值？

① 大错误惩罚更重

误差绝对值平方
111
224
1010100

平方让大误差被"放大"——模型会优先修正巨大错误。

② 数学上更容易求导

d/dx · x² = 2x

平方损失处处连续、平滑，导数计算极其简单——这对于梯度下降至关重要。

⚠️ 为什么不用绝对值？

绝对值的导数在 0 处不可导（"尖点"），且无论误差大小，梯度恒为 ±1，不会对巨大错误给予更大的修正力度。

6 梯度下降：整篇文章真正的灵魂

这是整个深度学习世界最核心的东西。

本质一句话

⬇️ 梯度下降

沿着"损失减小最快"的方向调整参数。

直觉理解：下山

你站在山顶，目标是最低点。但你：看不到全局，只能看脚下坡度。

哪里更陡，往哪里走——这就是梯度下降。

w ← w − η · ∂ℓ/∂w
符号含义
w参数（权重）
η (学习率)每次迈多大的步子
∂ℓ/∂w梯度——损失函数在当前参数处的"坡度"

⚠️ 学习率是核心超参数

太大 → 震荡发散；太小 → 收敛极慢。调学习率是炼丹的第一步。

7 为什么叫"学习"？

这一点非常关键：

传统编程机器学习
模式 人写规则 人定义目标
执行 机器执行 机器自己找规则
房价示例 if area>100: price+=100w 不给规则，只给数据，自己学
核心 逻辑编码 参数学习

🧠 学习的本质

不是人告诉机器规则，而是机器从数据中自动发现规律。这就是"参数学习"——找到一组参数，让预测尽可能准。

8 线性回归就是神经网络

文章最后一句非常重要："线性回归可以视为单层神经网络。"

很多人会忽略这句话——但这是整个深度学习的入口。

输入层 （x₁, x₂, …, xₙ）
↓ 权重 × 输入 + 偏置
输出层 （ŷ）

线性回归其实已经是神经网络了——只是中间没有隐藏层。

🔗 统一视角

线性回归 = 单层神经网络（无激活函数）
MLP = 线性回归 + 隐藏层 + 非线性激活函数
深度学习 = 叠加更多层

预测 → 计算损失 → 反向传播 → 更新参数 ↻

GPT 本质上就是"极其复杂的函数拟合器"。线性回归拟合直线，GPT 拟合语言世界——但核心训练逻辑完全一样。

10 隐藏重点：矢量化

文章专门讲到——不要用 for 循环，而要使用矩阵运算：

# ❌ 慢：Python for 循环
for i in range(n):
    y_hat[i] = w[i] * x[i]
y_hat += b

# ✅ 快：矢量运算
y_hat = X @ w + b

这是现代 AI 能跑起来的关键原因——因为 GPU 天生适合矩阵计算。

⚡ Transformer 本质

就是超大规模矩阵乘法。矢量化让深度学习从"可能"变成了"可行"。

12 你真正应该从这篇文章学到什么

不是公式。而是以下 四个核心认知：

📐 1. AI 本质是函数拟合

输入 x，输出 y。模型在学习 f(x) = y。

🔎 2. 神经网络本质是参数搜索

训练不是"记忆"，而是找到一组参数让误差最小。

🎯 3. 损失函数决定学习方向

损失函数不是附属品，而是 AI 的目标函数。你定义什么损失，AI 就会朝什么方向进化。

⚙️ 4. 梯度下降是现代 AI 的发动机

没有梯度下降，GPT、AlphaGo、Stable Diffusion 都不存在。

14 工程视角：建立"训练流水线"思维

如果你是后端/工程背景，最应该理解的是"训练流水线"，而不是公式推导。

数据 → 模型 → 前向传播 → loss → backward → optimizer.step()

这是整个 AI 工程世界的主干。以后 RAG、Agent、微调、RLHF、多模态——本质都在这个骨架上扩展。

# PyTorch 伪代码 —— 训练流水线
for epoch in range(num_epochs):
    for X, y in dataloader:       # ① 数据
        y_hat = model(X)              # ② 前向传播
        loss = loss_fn(y_hat, y)      # ③ 计算损失
        optimizer.zero_grad()
        loss.backward()               # ④ 反向传播
        optimizer.step()              # ⑤ 更新参数
