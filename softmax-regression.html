✦ 文章定位：比线性回归重要一个量级

线性回归解决的是预测一个连续值（房价、温度、销量）。

而 Softmax 回归解决的是："这个东西属于哪一类？"

  • 这是猫还是狗？
  • 这是不是垃圾邮件？
  • 这个词后面最可能接哪个词？

🤖 GPT 本质上就是超大型 Softmax 分类器

1 这篇文章真正想解决什么问题？

核心问题："如何让机器输出概率分布？"

例如，看到一张猫的图片，机器输出：

类别概率
🐱 猫90%
🐶 狗7%
🐦 鸟3%

机器不只是说"这是猫"，而是给出每个类别的概率。

💡 概率 = 不确定性的表达

这是现代 AI 极其核心的思想——机器不仅给出答案，还告诉你它有多确信。

2 为什么线性回归不适合分类？

这是文章最关键的切入点。

线性回归的输出是任意实数：

输出合理吗？
-3.2❌ 不合理
8.7❌ 不合理
1000❌ 不合理

但概率必须满足：

  • 0 ≤ p ≤ 1
  • 所有概率和 = 1

⚠️ 线性输出不能直接当概率

文章真正在解决：如何把任意数字压缩成合法概率。

3 Softmax 的本质是什么？

这是全文最核心的东西。

ŷᵢ = eoᵢ / Σⱼ eoⱼ

很多人第一次看到会疑惑：为什么突然出现 e？

💡 Softmax 本质是"概率竞争机制"

让每个类别通过指数函数放大差异，然后互相竞争——谁更强，谁就获得更高的概率。

举例：三分类

模型输出的原始值（logits）：

类别原始 logitelogitSoftmax 概率
猫 🐱2e² ≈ 7.397.39/11.1 ≈ 66%
狗 🐶1e¹ ≈ 2.712.71/11.1 ≈ 24%
鸟 🐦0e⁰ = 11/11.1 ≈ 9%

5 Softmax 真正的隐藏本质

很多人学完，只记住公式。但真正本质是：

🎯 Softmax 是"可导的 argmax"

argmax 的问题

传统分类中，谁最大选谁。但 argmax 不可导——无法反向传播。

Softmax 的解决方案

它是"平滑版最大值选择"：

  • ✅ 能表达竞争
  • ✅ 能表达概率
  • ✅ 可导，可训练

🏆 这就是它统治深度学习几十年的原因

6 交叉熵，才是这篇文章真正的灵魂

很多人以为 Softmax 是重点。其实交叉熵（Cross Entropy）才是真正核心。

L = − Σᵢ yᵢ · log(ŷᵢ)

🔥 "如果你非常自信但错了，我就狠狠干你"

7 为什么不用 MSE？

很多人这里没真正理解。分类问题如果用 MSE，会有严重问题。

举例

真实：[猫=1, 狗=0]

预测MSE交叉熵
猫=0.9, 狗=0.1 0.02 ✅ 0.05 ✅
猫=0.6, 狗=0.4 0.32 0.92 🔺
猫=0.01, 狗=0.99 0.98 4.6 💥

⚠️ MSE 惩罚不够狠

分类最怕——高置信度预测错误。交叉熵对这种错误的惩罚是指数级的，而 MSE 只是线性增长。

8 交叉熵的真正意义

交叉熵的公式：

L = − log(ŷtrue)
真实类别的预测概率交叉熵损失含义
0.99 −log(0.99) ≈ 0.01 几乎没损失 ✅
0.50 −log(0.50) ≈ 0.69 有一定惩罚
0.0001 −log(0.0001) ≈ 9.2 💥 瞬间爆炸

9 为什么要用 log？

这是非常深的地方。log 本质是在做信息量编码。

信息论里：越不可能的事件，信息量越大。

事件概率信息量
太阳升起极高很低
明天世界毁灭极低极高

📡 交叉熵本质

"真实答案出现时，你有多惊讶？"——越惊讶（概率越低），损失越大。

这是全文最容易被忽略，但最重要的内容之一。

🎯 文章其实在说："让真实标签出现的概率最大"

模型输出真实类概率评价

📐 训练目标 = 最大化真实类别概率

13 为什么说 Softmax 是"语言世界的核心"？

因为语言本质是——"下一个 token 分类问题"。

输入序列（token 嵌入）
↓ Transformer 层层变换
隐藏表示
↓ 线性层 → 词表大小的 logits
Softmax → 下一个 token 概率分布

词表有 5 万词——模型本质上在 5 万个类别里做分类。

P(tokenᵢ) = ezᵢ / Σⱼ ezⱼ

GPT 最后一层就是 Softmax

14 Softmax 不关心绝对值，只关心相对大小

[1, 2, 3]  →  Softmax  →  [0.09, 0.24, 0.67]
[101, 102, 103]  →  Softmax  →  [0.09, 0.24, 0.67]

结果完全一样。

🔄 因为公共偏移会抵消

Softmax 只关心类别之间的差值，而不是它们的绝对大小。

15 为什么"只关心相对大小"这点重要？

因为神经网络真正重要的是"相对能量"，不是绝对值。

这个思想后来会演化成：

Attention Score · Energy-based Model · Logits

16 Logits 是什么？

文章虽然没有重点强调，但 Softmax 前面的值 oᵢ 就是 logits。

📐 Logits = 未归一化概率

现代 AI 中 logits 无处不在：

  • Logits masking — 在语言模型中屏蔽非法 token
  • Logits bias — 人为调整某些类别的倾向
  • Temperature scaling — 控制概率分布的平滑程度

17 Temperature（温度）本质是什么？

虽然文章没讲，但这是 Softmax 的直接延伸。

Pᵢ = ezᵢ / T / Σⱼ ezⱼ / T
T效果含义
T → 0 概率尖锐 更确定（几乎总是选最高概率类别）
T = 1 标准 Softmax 正常概率分布
T → ∞ 概率平滑 更随机（各类别概率趋近相等）

拖动温度滑块观察分布变化

🎲 GPT 采样本质 = 调 Softmax 的形状

低温度 → 更确定、更保守；高温度 → 更有创造性、更多样。

18 这篇文章真正建立了什么？

🧠 神经网络分类范式

输入 → 线性层 → logits → Softmax → 概率 → Cross Entropy → Backward

后面几乎所有分类模型——CNN 分类器、BERT、GPT、ViT——都还是这一套。

19 你真正应该从这篇文章学到什么

📊 1. 分类本质是概率建模

不是"选答案"，而是预测概率分布。

⚔️ 2. Softmax 本质是竞争机制

不是普通激活函数，而是类别之间的竞争系统。

📡 3. Cross Entropy 是信息论思想

不是简单 loss，而是真实分布与预测分布之间的信息差。

🤖 4. GPT 本质是 token 分类器

LLM 能生成语言，是因为它一直在预测下一个 token 的概率。
