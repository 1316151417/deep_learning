🤔 为什么深度学习需要微积分？

训练神经网络本质上是在做一件事：找到让"错误"最小的参数。这个过程叫优化。

想象你站在一座山上想下山——你每次都往最陡的方向走一步。这个"最陡的方向"就是梯度，而梯度来自导数。

微积分在深度学习中的角色：

📉 导数 → 函数在某点的瞬时变化率（切线的斜率）

📊 偏导数 → 多元函数对某一个变量的变化率

🧭 梯度 → 所有偏导数组成的向量，指向函数增长最快的方向

⛓️ 链式法则 → 复合函数求导，反向传播算法的数学基础

1️⃣ 导数 Derivative

定义

导数描述函数在某一点的瞬时变化率。直观理解：函数曲线在该点切线的斜率。

f'(x) = lim[h→0] ( f(x+h) − f(x) ) / h

分子 f(x+h) − f(x) 是函数值的变化量，分母 h 是自变量的变化量。当 h 趋近于 0，这个比值就是那一点的导数。

等价记号：f'(x) = dy/dx = df/dx = Df(x)

3️⃣ 求导法则

四大法则

① 常数相乘：d/dx[C·f(x)] = C·f'(x) — 常数可以"提出来"

② 加法法则：d/dx[f(x)+g(x)] = f'(x) + g'(x) — 和的导数 = 导数的和

③ 乘法法则：d/dx[f(x)·g(x)] = f(x)g'(x) + g(x)f'(x) — 前导后不导 + 后导前不导

④ 除法法则：d/dx[f(x)/g(x)] = (g·f' − f·g') / g² — 分子导分母不导 − 分母导分子不导，除以分母平方

4️⃣ 偏导数 Partial Derivative

定义

当函数有多个自变量时（如 f(x₁, x₂, ..., xₙ)），偏导数 = 只对其中一个变量求导，把其他变量当作常数。

∂y/∂xᵢ = lim[h→0] ( f(x₁,...,xᵢ+h,...,xₙ) − f(x₁,...,xᵢ,...,xₙ) ) / h

记号：∂y/∂xᵢ = ∂f/∂xᵢ = f_{xᵢ} = Dᵢf（注意用弯的 ∂ 而非直的 d）

例子：f(x,y) = 3x² + 5xy + y³，则 ∂f/∂x = 6x + 5y（把 y 当常数），∂f/∂y = 5x + 3y²（把 x 当常数）。

5️⃣ 梯度 Gradient

定义

梯度是所有偏导数组成的向量，指向函数增长最快的方向。

∇f(x) = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]ᵀ

倒三角 ∇ 读作 "nabla"，∇f 就是一个包含所有偏导数的向量。

深度学习中的意义：梯度指向损失函数增长最快的方向，所以我们要往反方向（负梯度）走，才能让损失变小！

6️⃣ 链式法则 Chain Rule

定义

链式法则用于求复合函数的导数。如果 y = f(u) 且 u = g(x)，则：

dy/dx = dy/du · du/dx

多变量情形：如果 y 依赖 u₁, u₂, ..., uₘ，每个 uᵢ 又依赖 x₁, x₂, ..., xₙ，则：

∂y/∂xᵢ = Σⱼ (∂y/∂uⱼ · ∂uⱼ/∂xᵢ)

🔥 深度学习核心：反向传播（Backpropagation）就是链式法则在整个神经网络上的应用！从输出层往回逐层求梯度，每一步都是链式法则。
