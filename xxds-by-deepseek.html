🤔 为什么需要线性代数？

想象你在用一张表格记录学生的成绩——每行是一个学生，每列是一门课。这个表格就是矩阵。

当你想算"加权总分"时，就是在做向量点积。当你想把所有分数统一乘以一个系数，就是在做标量乘法。

深度学习的核心——神经网络——本质上就是一层层的矩阵乘法。理解线性代数是理解深度学习的入场券。

本文从四个基本对象出发：标量 → 向量 → 矩阵 → 张量，逐一介绍它们的运算规则。

1️⃣ 标量 Scalar

定义

标量就是单个数字。比如你的年龄 25，气温 36.5°C，或者圆周率 π ≈ 3.14159。

数学上用一个普通小写字母表示，如 x = 42，并写作 x ∈ ℝ（读作 "x 属于实数集"）。

在代码中，标量就是只有一个元素的张量。

2️⃣ 向量 Vector

定义

向量就是一组有序的数字。可以把它想象成一个有方向的箭头，或者一张只有一列的迷你表格。

数学上用粗体小写字母表示，如 x = [x₁, x₂, x₃]ᵀ。默认是列向量（竖着写）。

向量的维度 = 它包含的元素个数。比如 [2, 7, 1] 是一个 3 维向量。

3️⃣ 矩阵 Matrix

定义

矩阵就是一个二维的数字表格（有行和列）。用粗体大写字母表示，如 A ∈ ℝ³ˣ² 表示 3 行 2 列的矩阵。

每个数据样本通常作为矩阵中的一行（行向量）。行数 = 列数时叫 方阵。

元素 aᵢⱼ 表示第 i 行、第 j 列的值。

4️⃣ 张量 Tensor

定义

张量是"任意数量轴的n维数组"的通用叫法。

标量 = 0 阶张量（没有轴）→ 一个数
向量 = 1 阶张量（1 个轴）→ 一维数组
矩阵 = 2 阶张量（2 个轴）→ 二维数组
3阶+张量 = 3个以上轴 → 彩色图像就是3阶张量！

一张 256×256 的彩色照片 = 形状 (256, 256, 3) 的三阶张量（高 × 宽 × RGB通道）。

⚠️ 注意："维度"一词在向量中指长度（几个元素），在张量中指轴的数量（几阶），容易混淆！

5️⃣ 按元素运算 & Hadamard 积

核心规则

两个相同形状的矩阵/向量，可以逐个位置进行加减乘除。结果形状不变。

A ⊙ B 叫 Hadamard 积——就是按元素做乘法，不是矩阵乘法！

标量与张量运算：张量 ±/* 标量 = 每个元素都 ±/* 那个标量，形状不变。

点击按钮 👆 Hadamard积 ≠ 矩阵乘法！

6️⃣ 转置 Transpose

定义

转置就是交换矩阵的行和列。记作 Aᵀ。

如果 B = Aᵀ，那么 bᵢⱼ = aⱼᵢ——第 i 行第 j 列变成了第 j 行第 i 列。

形状从 m × n 变成 n × m。

如果 A = Aᵀ（必须是方阵），叫对称矩阵。

性质：(Aᵀ)ᵀ = A，Aᵀ + Bᵀ = (A + B)ᵀ。

7️⃣ 点积 Dot Product

定义

两个相同长度的向量 x, y ∈ ℝᵈ，点积 = 对应位置相乘再求和。

xᵀy = x₁y₁ + x₂y₂ + ... + xₙyₙ = Σ xᵢyᵢ

应用：加权平均（权重非负且和为1时）、两个向量夹角的余弦值（归一化后）。

8️⃣ 矩阵-向量积

定义

矩阵 A ∈ ℝᵐˣⁿ 乘以向量 x ∈ ℝⁿ，得到长度为 m 的向量。

结果的第 i 个元素 = 矩阵第 i 行与向量 x 的点积。

前提：矩阵的列数必须 = 向量的维度！

这可以理解为：从 n 维空间到 m 维空间的线性变换。

9️⃣ 矩阵乘法 Matrix Multiplication

定义

A ∈ ℝⁿˣᵏ × B ∈ ℝᵏˣᵐ = C ∈ ℝⁿˣᵐ

每个元素 cᵢⱼ = A第i行 与 B第j列 的点积。

前提：A 的列数必须 = B 的行数（都是 k）！

⚠️ 矩阵乘法 ≠ Hadamard积！前者是"行×列的点积"，后者是"逐位置相乘"。

🔟 降维操作 Sum & Mean

核心操作

sum() — 沿所有轴求和，降维为标量

sum(axis=0) — 沿第 0 轴（行方向）求和，消掉行维度

sum(axis=1) — 沿第 1 轴（列方向）求和，消掉列维度

mean() — 平均值 = 总和 ÷ 元素个数

cumsum(axis=0) — 累积和，不降维

1️⃣1️⃣ 范数 Norm

定义与性质

范数是衡量向量"大小"的函数，记作 ‖x‖。满足：

① 齐次性：‖αx‖ = |α| ‖x‖（缩放 α 倍，范数也缩放 |α| 倍）

② 三角不等式：‖x + y‖ ≤ ‖x‖ + ‖y‖

③ 非负性：‖x‖ ≥ 0

④ 正定性：仅当所有元素为 0 时范数为 0

常用范数

L₂ 范数（欧几里得距离）：‖x‖₂ = √(Σ xᵢ²) — 最常用！

L₁ 范数（曼哈顿距离）：‖x‖₁ = Σ |xᵢ| — 对异常值不敏感

Frobenius 范数：矩阵版的 L₂，‖X‖_F = √(ΣΣ xᵢⱼ²)
