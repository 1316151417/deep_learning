2数学原理

线性回归的目标是找到一组参数 w、b，使预测值尽可能接近真实值。
ŷ = Xw + b
符号含义程序中的变量
X输入特征矩阵 (1000×2)features
w权重向量 (2×1)w
b偏置标量b
ŷ模型预测值linreg(X, w, b)
y真实标签labels
L = (ŷ − y)² / 2
w ← w − η · ∂L/∂w     b ← b − η · ∂L/∂b
核心思想：损失函数衡量预测与真实的差距；梯度指出参数应调整的方向；学习率 η 控制每步调整的幅度。反复迭代，损失逐步下降。

3生成合成数据

构造一个已知参数的线性数据集，加入少量高斯噪声模拟真实场景。
def synthetic_data(w, b, num_examples):
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)
    return X, y.reshape((-1, 1))
行作用
normal(0, 1, ...)从标准正态分布 N(0,1) 采样特征矩阵 X
matmul(X, w) + b计算理想线性关系 y = Xw + b
normal(0, 0.01, ...)加入标准差 0.01 的噪声 ε，模拟观测误差
reshape((-1, 1))将 y 变为列向量，便于后续批量计算

4小批量数据迭代器

将数据集打乱后按固定大小分批产出，每个 batch 包含一组特征和标签。
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(
            indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]
为什么打乱？如果样本有序，模型可能学到数据的顺序而非特征规律。yield 让函数成为生成器，每次只产出一个小批量，节省内存。

5模型 · 损失 · 优化器

三个函数分别对应深度学习的三个核心组件。
# 模型：线性变换
def linreg(X, w, b):
    return torch.matmul(X, w) + b

# 损失：均方误差
def squared_loss(y_hat, y):
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2

# 优化器：小批量随机梯度下降
def sgd(params, lr, batch_size):
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad_zero_()
组件函数关键点
模型linreg矩阵乘法 + 广播偏置，输出预测值 ŷ
损失squared_loss除以 2 是为了求导后系数为 1，方便计算
优化sgd在 no_grad 下更新参数，避免污染计算图；除以 batch_size 取均值梯度
为什么需要 no_grad？参数更新不是模型计算的一部分，用 with torch.no_grad() 告诉 PyTorch 不要追踪这步操作的梯度。grad.zero_() 清零梯度，防止累加。

6训练循环

将以上组件组合成完整的训练流程，反复迭代直到模型收敛。
true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = synthetic_data(true_w, true_b, 1000)

w = torch.normal(0, 0.01, size=(2,1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)

batch_size, lr, num_epochs = 10, 0.03, 3

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = squared_loss(linreg(X, w, b), y)
        l.sum().backward()
        sgd([w, b], lr, batch_size)
    with torch.no_grad():
        train_l = squared_loss(linreg(features, w, b), labels)
        print(f"epoch {epoch + 1}, loss {train_l.mean():f}")
步骤代码含义
1. 初始化w = normal(0, 0.01, ...)权重用小随机数初始化，偏置设为 0
2. 前向传播linreg(X, w, b)用当前参数计算预测值
3. 算损失squared_loss(y_hat, y)衡量预测与真实的差距
4. 反向传播l.sum().backward()自动计算所有参数的梯度
5. 更新参数sgd([w, b], lr, batch_size)沿梯度反方向调整参数
6. 评估train_l.mean()每个 epoch 结束在全量数据上评估

8超参数影响

三个超参数控制着训练的速度和效果，需要反复试验找到合适的值。
超参数当前值过小会怎样过大会怎样
lr 学习率0.03收敛极慢，loss 几乎不动震荡甚至发散，loss 不降反升
batch_size 批量大小10梯度噪声大，训练不稳定显存占用高，梯度过于平滑
num_epochs 迭代轮数3欠拟合，参数还未收敛过拟合风险，浪费计算
实验建议：试试将 lr 改为 0.00001，观察 loss 几乎不变（如原始 notebook 所示）；再改为 1.0，观察 loss 爆炸。动手调参是最好的理解方式。
