0 核心思想：为什么要随机丢弃？

过拟合的另一个原因是神经元之间产生了"共适应"（co-adaptation）：某些神经元过度依赖其他特定神经元的输出，导致模型对训练数据的特定模式过于敏感。

Dropout 的做法很暴力：训练时，每次前向传播随机将一部分神经元的输出置零。这样每个神经元都不能依赖"邻居"，必须独立地学习有用的特征。

Dropout 的工作原理

原始输出 h
→
随机 mask
→
h' = mask * h / (1-p)

以概率 p 将元素置零，保留的元素除以 (1-p) 做缩放，保证期望不变：E[h'] = h

直观类比

类比说明
团队协作如果每次开会随机一半人请假，每个人都必须学会独立完成工作，而不是依赖某几个"大腿"
集成学习每次 dropout 相当于训练一个不同的子网络，最终预测相当于所有子网络的集成
为什么除以 (1-p)？ 如果丢弃概率 p=0.5，保留的输出要乘以 2。这样即使训练时一半神经元被丢弃，输出的期望值和测试时（不丢弃）一致，不需要在测试时做任何调整。

1 从零实现：dropout_layer 函数

def dropout_layer(X, dropout):
    """以概率 dropout 丢弃元素，保留部分做 1/(1-p) 缩放"""
    assert 0 <= dropout <= 1
    if dropout == 1:
        return torch.zeros_like(X)    # 全部丢弃
    if dropout == 0:
        return X                      # 不丢弃
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)

逐行解读：

  • torch.rand(X.shape)：生成 [0,1) 均匀分布的随机数，形状和 X 一样
  • > dropout：大于 p 的位置为 True（保留），小于等于 p 的为 False（丢弃）
  • .float()：True→1.0，False→0.0，变成 mask
  • mask * X：被丢弃的位置变成 0
  • / (1.0 - dropout)：缩放保留的元素，保持期望不变

举例：dropout = 0.5

原始输出随机 mask结果（×2 缩放）
[0.8, 0.3, 0.5, 0.9][1, 0, 1, 0][1.6, 0, 1.0, 0]

原始均值 = 0.625，丢弃后均值 = 0.65，近似相等（随机性导致的微小差异）。

dropout=0 和 dropout=1 是特殊情况： 0 表示不丢弃（直接返回原值），1 表示全丢弃（返回全零）。这两个边界情况要单独处理，避免除以零。

2 训练 vs 测试：关键差异

训练时测试时
Dropout 开启：随机丢弃神经元 关闭：使用全部神经元
目的 打破共适应，防止过拟合 用完整网络做确定性预测
输出 随机的（每次不同） 确定的（每次相同）
缩放 保留元素除以 (1-p) 不需要缩放
为什么测试时不丢弃？ 测试时我们需要最稳定的预测。训练时已经通过缩放 (1/(1-p)) 保证了期望一致，所以测试时直接用全部神经元即可，不需要再做随机。

3 从零实现：带 Dropout 的 MLP

dropout1, dropout2 = 0.2, 0.5

class ScratchNet(nn.Module):
    def __init__(self, num_inputs, num_outputs,
                 num_hiddens1, num_hiddens2, is_training=True):
        super().__init__()
        self.training = is_training
        self.lin1 = nn.Linear(num_inputs, num_hiddens1)
        self.lin2 = nn.Linear(num_hiddens1, num_hiddens2)
        self.lin3 = nn.Linear(num_hiddens2, num_outputs)
        self.relu = nn.ReLU()

    def forward(self, X):
        H1 = self.relu(self.lin1(X))
        if self.training:
            H1 = dropout_layer(H1, dropout1)  # 第一层后 dropout
        H2 = self.relu(self.lin2(H1))
        if self.training:
            H2 = dropout_layer(H2, dropout2)  # 第二层后 dropout
        return self.lin3(H2)

关键设计：

  • 用 self.training 标志控制是否启用 dropout
  • 训练时：ReLU 输出经过 dropout 后再传给下一层
  • 测试时：跳过 dropout_layer，直接传递
  • 两个隐藏层使用不同的丢弃率（0.2 和 0.5）

两个丢弃率不同？ 通常靠近输入的层用较小的 p（如 0.2），靠近输出的层用较大的 p（如 0.5）。因为靠近输出的层更容易过拟合，需要更强的正则化。

4 简洁实现：nn.Dropout

net = nn.Sequential(
    nn.Linear(64, 256),
    nn.ReLU(),
    nn.Dropout(0.2),        # 第一个隐藏层后
    nn.Linear(256, 256),
    nn.ReLU(),
    nn.Dropout(0.5),        # 第二个隐藏层后
    nn.Linear(256, 10)
)

PyTorch 的 nn.Dropout 自动处理了训练/测试模式的切换。

从零实现 vs 简洁实现

从零实现简洁实现
手写 dropout_layer() 函数 nn.Dropout(p)
用 self.training 手动判断 net.train() / net.eval() 自动切换
手动处理 mask 和缩放 PyTorch 内部自动处理 
# 训练时
net.train()    # Dropout 生效
y_hat = net(X_batch)

# 测试时
net.eval()     # Dropout 自动关闭
with torch.no_grad():
    test_acc = accuracy(net(X_test), y_test)
net.train() vs net.eval()： 这两个方法切换模型的模式。除了 Dropout，BatchNorm 等层在两种模式下行为也不同。养成好习惯：训练前 train()，测试前 eval()。

观察： 在 digits 数据集上，Dropout 的提升不算剧烈（数据量较小），但测试准确率确实更高。在更大的数据集和更深的网络上，Dropout 的效果会更加显著。
训练时 loss 会更高？ 这是正常的！Dropout 让训练变得更"难"（每次只有部分神经元工作），所以训练 loss 通常比不用 Dropout 时高。但测试 loss 会更低，这才是我们关心的。

Dropout vs 权重衰减

权重衰减Dropout
原理 惩罚大权重（L2 正则化） 随机丢弃神经元，打破共适应
作用对象 权重参数 w 隐藏层的输出值
超参数 λ（惩罚强度） p（丢弃概率）
实现方式 optimizer 的 weight_decay 参数 nn.Dropout(p) 层
训练时影响 损失函数多一项惩罚 前向传播随机屏蔽神经元
测试时影响 无特殊处理 需要 net.eval() 关闭
能否同时用？ 可以！两者互补，同时使用效果更好

关键知识点

概念说明
无偏性 保留元素除以 (1-p)，保证 E[h'] = h，训练和测试的期望一致
共适应 神经元之间过度依赖，Dropout 强迫每个神经元独立学习
train/eval 模式 训练时 Dropout 开启，测试时关闭。用 net.train() 和 net.eval() 切换
丢弃率选择 常用 0.1~0.5，靠近输出的层可以用更大的 p
