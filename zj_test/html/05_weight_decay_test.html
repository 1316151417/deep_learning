0 核心思想：为什么要限制权重？

过拟合的本质是模型"记住"了训练数据的噪声，而不是学到真正的规律。一个表现就是：权重值变得非常大，因为大权重可以让模型拟合任意细节。

权重衰减的解决思路很简单：在损失函数上加一个惩罚项，让大的权重"不划算"。

带正则化的损失函数

L(w, b) + λ/2 · ‖w‖²

第一项是原来的损失（如 MSE），第二项是 L2 惩罚。λ 越大，对大权重的惩罚越重。

SGD 更新规则的变化

无衰减： w ← w - η · ∂L/∂w
有衰减： w ← (1 - ηλ) · w - η · ∂L/∂w

每次更新时，权重先乘以 (1 - ηλ) 缩小一点，再减去梯度。这就是"衰减"的由来。

L2 vs L1： L2 惩罚让权重均匀地变小；L1 惩罚会让部分权重变成精确的 0（特征选择）。权重衰减通常指 L2。
偏置不衰减： 通常只对权重 w 做正则化，不对偏置 b 做。因为偏置不影响模型复杂度，惩罚它没有意义。

1 生成数据：高维 + 少量样本

n_train, n_test, num_inputs, batch_size = 20, 100, 200, 5
true_w = torch.ones((num_inputs, 1)) * 0.01
true_b = 0.05

def synthetic_data(w, b, num_examples):
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)  # 加噪声
    return X, y.reshape((-1, 1))

故意制造一个容易过拟合的场景：

  • 200 个特征（高维）
  • 只有 20 个训练样本（数据极少）
  • 真实权重全是 0.01（很小）

为什么这个设置容易过拟合？

维度样本数情况
20020特征数是样本数的 10 倍，模型可以轻松"记住"所有训练样本

在这种"高维低样本"场景下，模型会把噪声当信号，学到一堆大权重来完美拟合训练集，但在测试集上表现很差。

真实情况： 真实权重是 0.01，如果模型学到的权重远大于此，说明它在拟合噪声。

2 从零实现：手动加 L2 惩罚

def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2

def train_scratch(lambd):
    w, b = init_params()
    net = lambda X: torch.matmul(X, w) + b

    for epoch in range(100):
        for X, y in train_iter:
            # 损失 = MSE + λ * L2惩罚
            l = squared_loss(net(X), y) + lambd * l2_penalty(w)
            l.sum().backward()
            sgd([w, b], lr, batch_size)

关键就一行：l = squared_loss(net(X), y) + lambd * l2_penalty(w)

逐行解读

代码作用
l2_penalty(w)计算 ‖w‖²/2，即所有权重的平方和除以 2
lambd * l2_penalty(w)乘以 λ，控制惩罚强度
+ lambd * l2_penalty(w)加到原始损失上，组成新的目标函数
l.backward()对新的总损失求梯度，L2 项的梯度是 λw
手动 SGD 更新时，衰减是怎么发生的？

L2 惩罚对 w 的梯度是 λw，所以 SGD 更新变成：

w -= lr * (grad + λw) = (1 - lr*λ) * w - lr * grad

权重每次更新都会被 (1 - lr*λ) 缩小，自然趋向于小值。

3 简洁实现：PyTorch 的 weight_decay 参数

# 关键：weight_decay 只应用于权重，不应用于偏置
trainer = torch.optim.SGD([
    {"params": net[0].weight, "weight_decay": wd},
    {"params": net[0].bias}
], lr=lr)

PyTorch 的优化器内置了 weight_decay 参数，等价于手动加 L2 惩罚。

两种写法的等价关系

从零实现简洁实现
loss + λ * l2_penalty(w) "weight_decay": λ
手动在损失上加 L2 项 optimizer 在更新时自动做衰减
必须分开设置参数！

错误写法：SGD(net.parameters(), lr=lr, weight_decay=wd) — 这会连偏置一起衰减。

正确写法：用参数列表分别指定哪些参数需要衰减。偏置的 dict 里不写 weight_decay，默认就是 0。

关键知识点

概念说明
权重衰减 在损失函数上加 λ/2·‖w‖²，惩罚大权重，缓解过拟合
衰减机制 每次更新时权重乘以 (1-ηλ)，逐渐缩小
λ 的选择 λ 太小没效果，λ 太大模型学不动。通常通过验证集调参
偏置不衰减 偏置不影响模型复杂度，惩罚它没有意义
PyTorch 实现 optim.SGD 的 weight_decay 参数，需分开设置权重和偏置的参数组
