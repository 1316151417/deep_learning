0 核心思想：为什么需要卷积神经网络？

全连接网络（MLP）处理图像时有两个致命问题：参数量爆炸和忽略空间结构。一张 28×28 的灰度图展平后有 784 个输入，第一个隐藏层若有 256 个神经元，仅第一层就需要 784×256 ≈ 20 万个参数。

CNN 通过两个关键思想解决这些问题：

CNN 的两大支柱

机制含义效果
局部感受野 每个神经元只看输入的一个小区域（如 3×3） 大幅减少参数量
参数共享 同一个卷积核在整个输入上滑动，共享权重 参数量与输入尺寸无关

直观类比

类比说明
人眼扫视你看一张照片时，不会同时看所有像素，而是聚焦局部区域，逐步拼出全貌
特征检测器每个卷积核就像一个"特征探测器"，专门检测某种模式（边缘、纹理、形状）
MLP vs CNN 的参数量对比： 对于 28×28 输入，MLP 第一层需要 ~20 万参数，而一个 3×3 卷积核只有 9 个参数。即使有 32 个卷积核，也才 288 个参数——少了近 1000 倍。

1 卷积层：局部特征提取

卷积操作的核心：用一个小的卷积核（filter/kernel）在输入上滑动，每个位置做元素相乘再求和，生成一个输出值。

output[i, j] = Σ input[i+m, j+n] × kernel[m, n] + bias

3×3 卷积核的工作过程

输入区域 (3×3)卷积核 (3×3)输出
[1,2,3; 4,5,6; 7,8,9][1,0,-1; 1,0,-1; 1,0,-1](1-3)+(4-6)+(7-9) = -6

这个核检测垂直边缘：左边正值、右边负值，水平差异大的地方输出绝对值大。

关键参数

参数含义本代码中的值
in_channels输入通道数（灰度=1，RGB=3）1 或 32 或 64
out_channels卷积核个数，决定输出通道数32 或 64
kernel_size卷积核尺寸3
padding输入边缘填充的圈数1
padding=1 的作用： 不加 padding 时，3×3 卷积会让输出比输入小 2 像素。加 padding=1（在边缘补一圈零）后，输出尺寸和输入相同，方便堆叠多层。

输出尺寸公式

H_out = (H_in + 2×padding - kernel_size) / stride + 1

例：H_in=28, padding=1, kernel=3, stride=1 → H_out = (28+2-3)/1+1 = 28（尺寸不变）

2 池化层：降采样与不变性

池化（Pooling）的作用是对特征图进行降采样，减少数据量的同时增强模型对微小位移的鲁棒性。

最大池化 (MaxPool2d) 工作过程

输入 (4×4)2×2 最大池化输出 (2×2)
[1, 3, 2, 4]
[5, 6, 1, 2]
[3, 2, 7, 8]
[1, 4, 3, 6]		 每个 2×2 区域取最大值 [6, 4]
[4, 8]

池化层的作用

作用说明
降维2×2 池化将特征图尺寸减半，减少后续计算量
平移不变性目标移动一两个像素，池化后的输出几乎不变
扩大感受野后层神经元"看到"的输入区域更大，能捕捉更大范围的特征
池化没有可学习参数： 池化层只做固定的取最大值（或求平均）操作，不参与梯度计算和参数更新。

为什么用两层 Conv 再池化？ 两个 3×3 卷积的感受野等价于一个 5×5 卷积，但参数更少（2×9=18 vs 25），非线性更强（两次 ReLU）。这是 VGG 网络的核心思想。

4 ModernCNN 实现：PyTorch 代码逐行解析

4.1 网络定义

class ModernCNN(nn.Module):

    def __init__(self):
        super().__init__()

        # ===== 特征提取部分 =====
        self.features = nn.Sequential(
            # 第一个卷积块
            nn.Conv2d(1, 32, kernel_size=3, padding=1),  # 1通道 → 32通道
            nn.ReLU(),

            nn.Conv2d(32, 32, kernel_size=3, padding=1), # 32通道 → 32通道
            nn.ReLU(),
            nn.MaxPool2d(2),                                # 尺寸减半：28→14

            # 第二个卷积块
            nn.Conv2d(32, 64, kernel_size=3, padding=1), # 32通道 → 64通道
            nn.ReLU(),

            nn.Conv2d(64, 64, kernel_size=3, padding=1), # 64通道 → 64通道
            nn.ReLU(),
            nn.MaxPool2d(2)                                 # 尺寸减半：14→7
        )

        # ===== 分类器部分 =====
        self.classifier = nn.Sequential(
            nn.Linear(64 * 7 * 7, 128),  # 3136 → 128
            nn.ReLU(),
            nn.Linear(128, 10)              # 128 → 10（10个数字类别）
        )

设计要点

设计原因
features + classifier 分离职责清晰：features 提取特征，classifier 做分类
通道数递增 1→32→64浅层检测简单特征（边缘），深层检测复杂特征（形状）
两层 Conv 后接 MaxPool充分提取特征后再降采样，避免信息过早丢失
最终 64×7×7 = 3136 维两次 2×2 池化将 28 变为 7

4.2 前向传播

    def forward(self, x):
        x = self.features(x)          # 特征提取：(B,1,28,28) → (B,64,7,7)
        x = x.view(x.size(0), -1)  # 展平：(B,64,7,7) → (B,3136)
        x = self.classifier(x)        # 分类：(B,3136) → (B,10)
        return x
x.view(x.size(0), -1)： 保留 batch 维度，将剩余维度自动展平。-1 表示 PyTorch 自动计算该维度大小（64×7×7=3136）。这是 CNN 过渡到全连接层的标准操作。

Momentum 的作用： 想象球滚下山坡，动量让它保持之前的运动方向。在梯度方向一致的维度加速，在梯度方向变化的维度减速，从而更快收敛。

5.3 训练循环

for epoch in range(EPOCHS):

    model.train()           # 开启训练模式（影响 Dropout、BatchNorm 等）
    total_loss = 0

    for images, labels in train_loader:

        images = images.to(DEVICE)   # 数据搬到 GPU/MPS
        labels = labels.to(DEVICE)

        optimizer.zero_grad()        # 清空上一步的梯度

        outputs = model(images)      # 前向传播

        loss = criterion(outputs, labels)  # 计算损失
        loss.backward()              # 反向传播：计算梯度
        optimizer.step()             # 更新参数

        total_loss += loss.item()

    print(f"Epoch [{epoch+1}/{EPOCHS}] Loss: {total_loss / len(train_loader):.4f}")

训练四步曲

zero_grad()

→

每个 batch 都重复这四步。为什么先 zero_grad？ 因为 PyTorch 默认累加梯度，不清零会导致梯度越来越大。

5.4 测试评估

model.eval()               # 切换到评估模式
correct = 0
total = 0

with torch.no_grad():      # 禁用梯度计算，节省内存和计算
    for images, labels in test_loader:
        images = images.to(DEVICE)
        labels = labels.to(DEVICE)

        outputs = model(images)
        _, predicted = torch.max(outputs, 1)  # 取概率最大的类别

        total += labels.size(0)
        correct += (predicted == labels).sum().item()

accuracy = 100 * correct / total
print(f"\nTest Accuracy: {accuracy:.2f}%")
torch.max(outputs, 1)： 返回每行最大值及其索引。索引就是预测的类别（0-9），与真实标签比较即可计算准确率。

6 总结：CNN vs 全连接网络

CNN vs MLP 对比

MLP（全连接）CNN（卷积）
参数量 784×256 = 200,704（仅第一层） ~467,818（整个网络）
空间结构 丢失（展平为一维向量） 保留（二维特征图）
特征提取 全局混合，无层次 局部 → 全局，逐层抽象
平移不变性 无 有（池化层提供）
适用场景 表格数据、简单任务 图像、视频、空间数据

CNN 核心组件总结

组件作用关键参数
Conv2d局部特征提取kernel_size, padding, stride
ReLU引入非线性无参数
MaxPool2d降采样、扩大感受野pool_size (通常 2×2)
Linear最终分类输入/输出维度

这就是几乎所有现代 CNN（VGG、ResNet、EfficientNet）的基本骨架，区别只在于怎么堆叠和连接这些积木。
