0 核心思想：序列数据为何特殊？

电影评分、股价、语音、文本、地震——它们的共同点是顺序很重要。“狗咬人”和“人咬狗”字完全相同，含义却天差地别。打乱序列，意义就消失了。

对于时间步 t 的观测 x_t，我们想预测它，依据是过去的全部历史：

xt ~ P(xt | xt-1, xt-2, …, x1)

问题在于：输入长度会随 t 不断增长，无法直接训练一个固定大小的网络。d2l 给出两种应对策略：

策略做法代表
自回归模型 只看固定长度 τ 的窗口：[xt-τ, …, xt-1] 本节使用 ✅
隐变量自回归 维护一个对过去的“总结” ht，每步更新它 RNN / LSTM / GRU
隐变量：ht = g(ht-1, xt-1)   |   预测：x̂t = P(xt | ht)
本节做最朴素的事：用自回归策略，τ=4。把过去的 4 个值当特征、下一个值当标签，丢进一个普通 MLP。它没有记忆，只是个“滑动窗口回归器”，却足以暴露序列预测的根本难题。
因果关系：时间是向前走的，未来不能影响过去。所以我们始终只用过去预测未来（外推 extrapolation），训练时绝不混入未来数据。这正是后面“多步预测会崩”的根源。

1 生成数据：动力学不变 + 可加性噪声

用一条正弦波加上高斯噪声当玩具序列：x_t = sin(0.01·t) + ε。规则（动力学）是固定的正弦，但每个观测都抖动。拖动下面的滑块改变噪声强度，感受“动力学不变、数值变化”。

import torch
T = 1000
time = torch.arange(1, T + 1, dtype=torch.float32)
x = torch.sin(0.01 * time) + torch.normal(0, sigma, (T,))

2 构造特征-标签对：滑窗

把一维序列用长度 τ=4 的窗口滑过，每个窗口是一个样本：4 个历史值为特征，紧接的下一个值为标签。

tau = 4
features = torch.zeros((T - tau, tau))
for i in range(tau):
    features[:, i] = x[i: T - tau + i]      # 第 i 列 = x 错位 i 步
labels = x[tau:].reshape((-1, 1))          # 标签 = x[4:]

# 前 600 个样本训练 (复用框架的 DataLoader, 自动分批+打乱)
train_iter = DataLoader(
    TensorDataset(features[:600], labels[:600]),
    batch_size=16, shuffle=True)

3 训练极简 MLP：复用框架模块

网络简单到不能再简单：两层全连接 + ReLU。损失用 MSE，优化器用 Adam。全部复用 torch.nn，零自定义实现。

def get_net():
    return nn.Sequential(
        nn.Linear(4, 10),   # 输入 = τ 个历史值
        nn.ReLU(),
        nn.Linear(10, 1),    # 输出 = 下一步的预测值
    )

loss_fn = nn.MSELoss(reduction="none")
optimizer = torch.optim.Adam(net.parameters(), lr=0.01)

for epoch in range(5):
    for X, y in train_iter:
        optimizer.zero_grad()
        l = loss_fn(net(X), y)
        l.sum().backward()        # 与 d2l 一致: 按批求和反传
        optimizer.step()

4 ⭐ 单步 vs 多步预测：误差累积

模型训练好了，怎么用它预测？这里藏着一个大坑。拖动滑块、勾选曲线，亲眼看看两种预测的天壤之别。

效果 贴近真实曲线 很快坍缩成常数
原因 每步都有“正确答案”兜底 错误被一步步放大
误差累积：εk = ε̄ + c·εk-1   →   预测越远，偏离越快

为什么多步会崩？ 假设第 1 步积累误差 ε₁=ε̄。第 2 步的输入被 ε₁ 扰动，误差变成 ε₂=ε̄+c·ε₁……每一步都把上一步的误差再放大一次，指数级偏离。就像天气预报：未来 24 小时挺准，一周后基本靠猜。
真实运行结果（σ=0.2）： 单步 MSE = 0.060，多步 MSE = 1.811 —— 相差约 30 倍。这正是上面模拟器要传达的现象。

四条核心结论

结论说明
内插 ≠ 外推 用真实历史做单步（内插）很准；用自己的预测往前滚（外推）很快崩。训练时务必尊重时间顺序。
自回归 vs 隐变量 本节用固定窗口 τ 的自回归模型；维护隐藏状态 ht 的隐变量模型（RNN）是后续内容。
不可约误差 训练 loss 收敛到 ≈ σ²（噪声方差）即最优，再多训练也无法预测随机噪声本身。
误差累积 k 步预测：k 越大误差累积越快。短期预测可用，长期预测需要更强的记忆结构。
下一步学什么？ 自回归 MLP 没有记忆，窗口一滑过去就忘了。要捕捉长程依赖，需要循环神经网络（RNN）——它就是“隐变量自回归模型”的神经网络实现：用一个隐藏状态 ht 压缩所有历史。
