0 核心思想：语言模型给序列打分

语言模型（Language Model, LM）的目标是估计一段文本序列的联合概率 P(x_1, x_2, ..., x_T)。会"打分"的模型，既能评估一句话多"像自然语言"，也能用过去预测下一个 token 来生成新文本。

1 ⭐ 链式法则 → 马尔可夫假设 → n-gram

由概率的链式法则，一段长度 T 的序列的联合概率可以逐个 token 拆开：

P(x_1, ..., x_T) = ∏t=1..T P(x_t | x_1, ..., x_t−1)

问题是历史越长，条件分布越难估计（数据稀疏 + 维度爆炸）。马尔可夫假设：只依赖最近 n−1 个 token，于是：

n-gram:   P(x_t | x_<t) ≈ P(x_t | x_t−n+1, ..., x_t−1) 
def ngram_counts(corpus, n):
    seq = corpus.tolist()
    return collections.Counter(
        tuple(seq[i:i+n]) for i in range(len(seq)-n+1))

2 ⭐ Zipf 律：n-gram 阶数越高，长尾越平

§8.2 见过 unigram 的 Zipf 律 f(r) ∝ 1/r。把 1/2/3-gram 的频次都画在 log-log 坐标上对比，能看到 n 越大，曲线越平、越高频词占比越低——因为组合爆炸稀释了每个 n-gram 的频次。

Zipf 的工程后果：频次越高，"the/of the/the time traveller"这类高频组合把概率质量几乎吃光；绝大多数 n-gram 频次为 1，MLE 给它们的 P=1/N，遇到没见过的组合概率直接为 0。这就是平滑（smoothing）和神经语言模型被发明的根本动机。

3 ⭐ 困惑度 perplexity：语言模型的统一指标

语言模型的训练目标是最大化序列的对数似然，等价于最小化平均负对数似然。困惑度就是它的指数：

ppl = exp( 1/N Σt −log P(x_t | history) )

ppl=k 可以直观理解为"模型每次在 k 个等概率候选词之间犹豫"。ppl=1 完美，ppl=|V| 等同瞎猜。下面用 unigram MLE（P(w)=count(w)/N）作为玩具 LM 给句子打分。

4 ⭐ 序列采样：把长序列切成训练小批

语言模型不能整条 3.3 万长的 corpus 一次塞进 RNN，需要切成 num_steps 长的子序列，再打包成 batch_size 个一批。d2l 给出两种策略：

策略子序列起点小批之间适用
随机采样 random 随机偏移 + 随机打乱 彼此独立，不连续 每个小批重置隐状态
顺序分区 sequential 固定起点，步长 = num_steps 首尾相接，连续 隐状态可跨批 detach 传递 
def seq_data_iter_sequential(corpus, batch_size, num_steps):
    offset = random.randint(0, num_steps)
    num_tokens = ((len(corpus)-offset-1)//batch_size)*batch_size
    Xs = corpus[offset:offset+num_tokens].reshape(batch_size, -1)
    Ys = corpus[offset+1:offset+1+num_tokens].reshape(batch_size, -1)
    for i in range(0, Xs.shape[1], num_steps):
        yield Xs[:, i:i+num_steps], Ys[:, i:i+num_steps]   # Y = X 右移一位

为什么 Y = X 右移一位？ 语言模型的任务是"已知前文预测下一个 token"。所以 X = corpus[i:i+steps]，Y = corpus[i+1:i+1+steps]，每个时间步都用 X_t 预测 Y_t = X_{t+1}。这就是 RNN 语言模型的训练信号。

5 SeqDataLoader：RNN 训练的标准接口

d2l 把采样逻辑封装成 SeqDataLoader，对外只暴露 (X, Y) 小批，X.shape = (batch_size, num_steps)。接口和 PyTorch 的 DataLoader 一致，可以直接 for X, Y in data_iter 迭代。

class SeqDataLoader:
    def __init__(self, batch_size, num_steps, use_random_iter, max_tokens):
        self.corpus, self.vocab = load_corpus(max_tokens)
        self.batch_size, self.num_steps = batch_size, num_steps

    def __iter__(self):
        fn = (seq_data_iter_random if self.use_random_iter
              else seq_data_iter_sequential)
        return fn(self.corpus, self.batch_size, self.num_steps)

四条核心结论

结论说明
链式法则是起点 语言模型把序列联合概率拆成条件概率之积。完整历史不可估，必须做近似。
n-gram 是截断近似 只看最近 n−1 个 token。n 越大表达越强，但唯一组合爆炸 → 数据稀疏 → MLE 不可靠。
困惑度统一指标 ppl=exp(平均 NLL)，可跨模型比较；ppl=k 表示每次在 k 个候选里犹豫。
RNN 解决稀疏 用连续隐状态压缩任意长历史，不必离散查表；这正是下一节 §8.5 的动机。
下一步：数据已就绪（X, Y 小批），概念已铺垫（条件概率 + 困惑度）。§8.5 将引入循环神经网络——用一个隐状态 H_t 把整段历史压缩成固定维向量，用梯度下降学 P(x_t | H_t)，彻底摆脱 n-gram 的离散查表。
