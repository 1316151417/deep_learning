0 核心思想：给网络装上"记忆"

上一节的语言模型用 n-gram 离散查表，组合爆炸 + 数据稀疏。循环神经网络（RNN）的思路是：用一条隐状态 Ht 把所有历史压缩成一个固定维向量，每一步用它和当前输入一起算下一步。

Xt 当前输入

Ht−1 历史记忆
→
Ht = tanh(XtWxh + Ht−1Whh + bh)
→
Ot 输出
对比无隐状态（MLP）有隐状态（RNN）
输出依赖 只看当前输入 Xt Xt + Ht−1（全部历史）
记忆能力 无 —— 同一输入永远给同一输出 有 —— 同一输入在不同历史下给不同输出
参数 Wxh, bh 多一个 Whh，沿时间共享
适用 静态数据（图像分类） 序列数据（文本、语音、时序）
关键洞察：RNN 的"循环"不是网络结构在重复，而是同一组参数 Wxh, Whh 在每个时间步被复用。展开成一条链后，它看起来像一个很深的网络——但所有"层"共享权重。这就是它能处理任意长序列的原因。

1 ⭐ RNN 沿时间展开

把循环按时间步 t = 1, 2, ..., T 展开成一条链。每个节点做相同计算：读取 Xt 和上一步的 Ht−1，更新成新的 Ht，再线性映射成输出 Ot。初始隐状态 H0 = 0。

Ht = φ(Xt Wxh + Ht−1 Whh + bh)   |   Ot = Ht Whq + bq

为什么是"权重共享"？ 不管序列多长，RNN 的参数量始终是 Wxh + Whh + Whq 三个矩阵，不随 T 增长。对比 n-gram：n 越大组合越爆炸；RNN 把"历史"压缩进固定维的 Ht，从根上规避了维度灾难。

2 ⭐ 训练：困惑度从 3197 一路降

RNN 语言模型的训练目标：每步用 Xt 预测下一个 token Yt，最小化交叉熵。指标困惑度 perplexity = 交叉熵的指数，ppl=k 表示"每次在 k 个候选词里犹豫"。训练前 ppl ≈ |V|（瞎猜），训练后越低越好。

ppl = exp( 1/N Σ −log P(Yt | X≤t) )

4 ⭐ 梯度裁剪：防爆炸的"安全阀"

RNN 沿时间展开后很深，反向传播时梯度要连乘很多次 Whh。若 ‖Whh‖>1 梯度指数增长 → 爆炸；若 <1 指数衰减 → 消失。梯度裁剪只治爆炸：把整个梯度向量的范数强行压到阈值 θ 以内。

g ← min(1, θ / ‖g‖) · g 
def grad_clipping(net, theta):
    params = [p for p in net.parameters() if p.requires_grad]
    norm = torch.sqrt(sum(torch.sum(p.grad ** 2) for p in params))
    if norm > theta:
        for p in params:
            p.grad[:] *= theta / norm   # 等比缩放, 不改方向

裁剪只防爆，不防消失。 梯度消失（‖Whh‖<1）时早期时间步的梯度趋零，模型学不到长程依赖——这是 RNN 的固有缺陷，正是后面 LSTM / GRU 用门控机制要解决的核心问题。

5 从零实现 vs torch.nn.RNN

d2l 给出两种实现。从零版手写 for x in X 的逐时间步循环，把公式逐行翻译成代码；简洁版用 torch.nn.RNN 一行搞定循环，再接一个 nn.Linear 把隐状态映射到 vocab 维。

从零实现 forward（逐时间步循环）

def forward(self, X, state):
    X = F.one_hot(X.T, self.vocab_size).type(torch.float32)  # (steps, batch, V)
    H = state
    outputs = []
    for x in X:                              # 沿时间步循环
        H = torch.tanh(x @ self.W_xh + H @ self.W_hh + self.b_h)
        outputs.append(H @ self.W_hq + self.b_q)
    return torch.cat(outputs, dim=0), H

简洁实现（nn.RNN 内部已封装循环）

rnn_layer = nn.RNN(vocab_size, num_hiddens)   # 内含 W_ih, W_hh, b

class RNNModel(nn.Module):
    def __init__(self, rnn_layer, vocab_size):
        super().__init__()
        self.rnn = rnn_layer
        self.linear = nn.Linear(rnn_layer.hidden_size, vocab_size)

    def forward(self, inputs, state):
        X = F.one_hot(inputs.T, self.vocab_size).type(torch.float32)
        Y, state = self.rnn(X, state)              # 一步完成全部时间步
        return self.linear(Y.reshape(-1, Y.shape[-1])), state

四条核心结论

结论说明
隐状态 = 历史压缩 Ht 用固定维度向量编码 X≤t 全部历史，参数量不随序列长度增长。
权重沿时间共享 所有时间步用同一组 Wxh, Whh，展开后看似很深但参数极少。
困惑度统一指标 ppl = exp(交叉熵)，从 ~|V| 降到 ~200，意味着模型从瞎猜变成"在 ~200 个候选词里犹豫"。
梯度裁剪治标 只防爆炸不防消失；长程依赖的梯度消失问题留给 LSTM/GRU 的门控。
下一步：RNN 已能学习序列依赖，但遇到长序列仍会"遗忘"早期信息（梯度消失）。§8.6/§8.7 的 LSTM 用遗忘门/输入门/输出门精细控制记忆的保留与更新，让信息能跨数百步流动——这是现代序列模型的基石。
