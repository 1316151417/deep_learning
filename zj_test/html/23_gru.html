D2L · GRU

让记忆有选择地流动

拖动重置门与更新门，观察候选状态和最终隐状态如何变化。

H̃ₜ = tanh(Xₜ + Rₜ × Hₜ₋₁)
Hₜ = Zₜ × Hₜ₋₁ + (1-Zₜ) × H̃ₜ
输入隐状态
R 接近 0候选状态忽略过去，更关注当前输入。
Z 接近 1旧隐状态直接保留，适合长期依赖。
Z 接近 0快速采用候选状态，适合短期变化。

self.gru = nn.GRU(vocab_size, 128, batch_first=True) y, state = self.gru(F.one_hot(x, vocab_size).float(), state) logits = self.out(y)
