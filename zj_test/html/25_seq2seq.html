0 核心思想：编码器-解码器

机器翻译的输入和输出都是变长序列，且长度不等。Seq2Seq 用两个 RNN 解决：编码器读完整个源序列，把信息压缩进一个固定形状的上下文变量 c（取编码器最终隐状态）；解码器以 c 为起点，一个 token 接一个 token地生成目标序列，直到吐出 <eos>。

为什么是两个 RNN？ 一个负责「理解」（编码），一个负责「表达」（解码）。二者层数和隐藏单元数必须相同，这样编码器的最终隐状态才能直接拿来初始化解码器。

1 编码器：GRU 读完整条源序列

嵌入层把每个源 token 变成向量，转置成「时间步在前」，喂给多层 GRU。返回每步输出和最终隐状态（后者即上下文 c）。

class Seq2SeqEncoder(nn.Module):
    def __init__(self, vocab_size, embed_size, num_hiddens, num_layers, dropout=0):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.GRU(embed_size, num_hiddens, num_layers, dropout=dropout)
    def forward(self, X, *args):
        # X: (batch, num_steps) → 嵌入 → (num_steps, batch, embed)
        return self.rnn(self.embedding(X).permute(1, 0, 2))
形状记忆：输入 (B, T) → 嵌入 (B, T, E) → permute (T, B, E)（GRU 要时间步在前）→ 输出 output (T, B, H)、state (layers, B, H)。

2 ⭐ 解码器与完整数据流

解码器的初始隐状态 = 编码器最终隐状态（init_state）。每个时间步，把上下文 c 与当前输入嵌入拼接后送入 GRU，再用线性层映射到词表维度。拖动下方时间步，完整体验「编码 → 上下文 → 逐词生成」。

class Seq2SeqDecoder(nn.Module):
    def __init__(self, vocab_size, embed_size, num_hiddens, num_layers, dropout=0):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.GRU(embed_size + num_hiddens, num_hiddens, num_layers, dropout=dropout)
        self.dense = nn.Linear(num_hiddens, vocab_size)
    def init_state(self, enc_outputs, *args):
        return enc_outputs[1]            # 编码器最终隐状态 = c
    def forward(self, X, state):
        X = self.embedding(X).permute(1, 0, 2)
        context = state[-1].repeat(X.shape[0], 1, 1)   # 每步都拼接 c
        output, state = self.rnn(torch.cat((X, context), 2), state)
        return self.dense(output).permute(1, 0, 2), state

上下文是瓶颈：整条源序列被压进一个定长 c。源序列越长，信息丢失越严重——这正是 §9.8「注意力机制」要解决的问题（让解码器每步动态关注源序列的不同位置）。

3 ⭐ 强制教学（Teacher Forcing）

解码器在训练时，每个时间步的输入不是模型自己的预测，而是真实的标签（右移一位、前补 <bos>、丢掉末尾 <eos>）。这叫强制教学，能让训练又快又稳。而推理时没有标签，只能把上一步的预测喂回去。

bos = torch.full((Y.shape[0], 1), tgt_vocab['<bos>'])
dec_input = torch.cat([bos, Y[:, :-1], 1])   # 强制教学：标签右移
Y_hat, _ = net(X, dec_input, X_valid_len)

训练-推理差异（exposure bias）：训练时总喂正确标签，模型没机会「纠正」自己的错误；推理时一旦某步预测错，后续步步受影响。这是 seq2seq 的经典痛点。

4 ⭐ 掩蔽损失：让 padding 不参与训练

同一个小批里句子长短不一，短的用 <pad> 补齐。但 <pad> 是「假」的，不该计入损失。sequence_mask 用 valid_len 把超出有效长度的位置清零。

def sequence_mask(X, valid_len, value=0):
    maxlen = X.size(1)
    mask = torch.arange(maxlen)[None, :] < valid_len[:, None]
    X[~mask] = value
    return X

class MaskedSoftmaxCELoss(nn.CrossEntropyLoss):
    def forward(self, pred, label, valid_len):
        weights = sequence_mask(torch.ones_like(label), valid_len)
        unweighted = super().forward(pred.permute(0, 2, 1), label)
        return (unweighted * weights).mean(dim=1)

5 ⭐ 预测（贪心解码）与 BLEU

贪心解码：从 <bos> 开始，每步取概率最高的 token，喂回下一步，遇到 <eos> 停止。BLEU 用 n-gram 精确度（越长权重越大）+ 简短惩罚评估翻译质量，1.0 为完美。

BLEU = exp(min(0, 1 − len_label / len_pred)) · ∏n=1..k pn1/2n
