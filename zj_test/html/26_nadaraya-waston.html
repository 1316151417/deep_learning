0 核心思想：注意力汇聚

给定训练数据 {(x₁,y₁), …, (xₙ,yₙ)}，要预测新输入 x 的输出 ŷ=f(x)。注意力的视角是：把 x 当作查询（query），把训练输入 xᵢ 当作键（key）、yᵢ 当作值（value）。输出是所有值的加权平均，权重由查询与键的关系决定：

f(x) = Σᵢ α(x, xᵢ) · yᵢ
α(x, xᵢ) = softmaxi( −½(x − xᵢ)² )   （高斯核，权重非负且和为 1）

关键直觉：高斯核 exp(−½(x−xᵢ)²) 让离查询越近的键获得越大的注意力。所以预测值主要由查询附近的训练点决定——这正是「注意力」的含义。Nadaraya-Watson 核回归（1964）因此被视为「带注意力机制的机器学习」的最早范例。

1 合成数据集

用一条非线性函数加噪声生成 50 个训练样本，另取 50 个测试点（无噪声）评估。训练点按 x 排序，方便后面观察注意力热力图的对角带状结构。

yᵢ = 2·sin(xᵢ) + xᵢ0.8 + ε,   ε ~ 𝒩(0, 0.5²)
n_train = 50
x_train, _ = torch.sort(torch.rand(n_train) * 5)   # 排序后的训练输入
def f(x):
    return 2 * torch.sin(x) + x ** 0.8
y_train = f(x_train) + torch.normal(0.0, 0.5, (n_train,))
x_test  = torch.arange(0, 5, 0.1)            # 50 个测试点
y_truth = f(x_test)

2 平均汇聚（最朴素的基线）

最简单的估计器：无视输入 x，把所有训练输出的均值当作任意查询的预测。它「不动脑子」——预测是一条水平线。

f(x) = (1/n) · Σᵢ yᵢ
y_hat = torch.repeat_interleave(y_train.mean(), n_test)   # 一条水平线
为什么差：平均汇聚完全丢弃了输入信息 x。无论查询在哪，预测都是同一个常数 ≈ y_train 的均值。测试 MSE 高达 0.897。改进的方向显而易见——让预测依赖查询位置。

3 ⭐ 非参数注意力汇聚（Nadaraya-Watson）

把高斯核代入注意力汇聚公式，得到非参数模型：把每个查询和所有键算高斯距离，softmax 成权重，再加权求值。没有任何可学习参数，全靠核函数本身。

f(x) = Σᵢ softmaxi( −½(x − xᵢ)² ) · yᵢ
# 每个测试点（查询）和所有训练点（键）算高斯核
X_repeat = x_test.repeat_interleave(n_train).reshape((-1, n_train))
attention_weights = F.softmax(-(X_repeat - x_train)**2 / 2, dim=1)
y_hat = attention_weights @ y_train

4 ⭐ 带参数注意力汇聚（可学习的 w）

非参数版有一致性的优点（数据足够多时收敛到最优），但我们也能轻松塞进一个可学习参数 w：在查询-键距离上乘 w。w 越大，高斯核越窄、权重越集中在最近邻——注意力越「尖锐」。

f(x) = Σᵢ softmaxi( −½((x − xᵢ)w)² ) · yᵢ
class NWKernelRegression(nn.Module):
    def __init__(self):
        super().__init__()
        self.w = nn.Parameter(torch.rand(1))          # 唯一可学习参数
    def forward(self, queries, keys, values):
        queries = queries.repeat_interleave(keys.shape[1]).reshape(-1, keys.shape[1])
        self.attention_weights = F.softmax(-((queries - keys) * self.w)**2 / 2, dim=1)
        return torch.bmm(self.attention_weights.unsqueeze(1), values.unsqueeze(-1)).reshape(-1)

训练时每个样本的输入与其余所有样本的「键-值」对计算（留一法），用 MSE + SGD。5 轮后学得 w ≈ 17.65。
