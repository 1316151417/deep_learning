1Python 改动只集中在 Decoder

25_seq2seq.py
context = state[-1].repeat(X.shape[0], 1, 1) output, state = self.rnn(torch.cat((X, context), 2), state)

所有目标时间步看到同一个上下文：编码器最后一层最终隐状态。

27_attention_seq2seq.py
query = hidden_state[-1].unsqueeze(1) context = self.attention(query, enc_outputs, enc_outputs, enc_valid_len) out, hidden_state = self.rnn(torch.cat((context, x.unsqueeze(1)), -1).permute(1, 0, 2), hidden_state)

每个目标时间步先用当前 decoder 隐状态查询全部 encoder 输出，再把新上下文送入 GRU。

2新增的 AdditiveAttention

query = decoder hiddenkeys = encoder outputsvalues = encoder outputs

Bahdanau 注意力的打分不是点积，而是先把 query 与 key 投影到同一个空间，相加后过 tanh，再压成一个分数。

class AdditiveAttention(nn.Module): def forward(self, queries, keys, values, valid_len): scores = self.W_v(torch.tanh( self.W_q(queries).unsqueeze(2) + self.W_k(keys).unsqueeze(1))).squeeze(-1) self.attention_weights = masked_softmax(scores, valid_len) return torch.bmm(self.dropout(self.attention_weights), values)
