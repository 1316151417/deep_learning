D2L 10.4 · Bahdanau Attention

每个目标词，都重新看一遍源句

普通 Seq2Seq 只用一个固定上下文 c。Bahdanau 注意力把解码器上一隐状态当 query，对所有编码器隐状态做加性注意力池化，得到随时间变化的 cₜ。

0固定上下文的问题

源序列
i won !
→
编码器 GRU
h₁ h₂ h₃
→
固定 c
所有解码步共享
瓶颈：源句越长，一个固定向量越难保存所有细节。Bahdanau 的做法是：每生成一个目标 token，都按当前解码状态重新分配源 token 权重。

1加性注意力

score(sₜ₋₁, hᵢ) = vᵀ tanh(Wq sₜ₋₁ + Wk hᵢ)
αₜᵢ = softmax(score)
cₜ = Σ αₜᵢ hᵢ

query 是上一时刻解码器隐状态，key/value 是所有编码器隐状态。权重 α 每个解码步都会变。

3解码器数据流

每一步先用 hidden state 查询编码器输出，得到 context，再把 context 与当前输入词嵌入拼接，送入 GRU。

query = hidden[-1].unsqueeze(1)
context = attention(query, enc_outputs, enc_outputs, valid_len)
x = torch.cat((context, embedding(x).unsqueeze(1)), -1)
out, hidden = gru(x.permute(1, 0, 2), hidden)
