self-attention · positional encoding

自注意力：每个 token 同时看见所有 token

这一节的核心很干净：Q、K、V 来自同一组输入，所以序列中任意两个位置可以一步连接；但并行性带来的代价是丢掉顺序，需要位置编码把“第几个 token”加回去。

1极简 PyTorch 写法

class PositionalEncoding(nn.Module): def __init__(self, num_hiddens, dropout=0, max_len=1000): P = torch.zeros(1, max_len, num_hiddens) X = torch.arange(max_len).reshape(-1, 1) / torch.pow( 10000, torch.arange(0, num_hiddens, 2) / num_hiddens) P[:, :, 0::2] = torch.sin(X) P[:, :, 1::2] = torch.cos(X)
attn = nn.MultiheadAttention(100, 5, batch_first=True) Y, W = attn(X, X, X, key_padding_mask=mask, need_weights=True) X.shape == Y.shape W.shape == (batch, query_len, key_len)

3位置编码把顺序加回来

sinusoidal positional encoding

偶数列用 sin，奇数列用 cos。越靠前的编码维度变化越快，越靠后的维度变化越慢，于是一个位置会被多种频率共同描述。

位置 i 12
维度 2j/2j+1 6 / 7
相对位移 δ 5

固定位置编码不只是记绝对位置。对任意固定偏移 δ，位置 i 的一对 sin/cos 值可以通过一个 2×2 旋转矩阵变成位置 i+δ 的值，这就是它能表达相对位置的原因。

p(i, 2j) = sin(i / 10000^(2j/d)) p(i, 2j+1) = cos(i / 10000^(2j/d))
