Transformer 翻译模型仍然是 encoder-decoder。变化在于：RNN 的“逐步读入”被 self-attention 替代；decoder 也不是靠 GRU 的隐状态滚动，而是用 masked self-attention 控制“只能看已经生成的目标词”。

1mask：让 padding 和未来词失声

sequence_mask 和 masked_softmax

注意力本质上是在一排 key 上做 softmax。如果句子被 padding 到固定长度，padding 位置不应该得到概率；如果是 decoder 自注意力，未来目标词也不应该得到概率。代码里先把非法位置改成一个极小值 -1e6，再 softmax，它们的概率就几乎是 0。

def masked_softmax(X, valid_lens):
    if valid_lens is None:
        return F.softmax(X, dim=-1)
    X = sequence_mask(X.reshape(-1, shape[-1]), valid_lens, -1e6)
    return F.softmax(X.reshape(shape), dim=-1)
mask intuition
self-attn 可看 0..3
未来位置 mask

2Scaled Dot-Product Attention

DotProductAttention

这是 Transformer 的最小原子。query 问：“我现在这个位置想找什么信息？” key 回答：“每个位置有什么特征可供匹配？” value 则是最终被加权汇总的信息。分数公式是 QKᵀ / sqrt(d)，除以 sqrt(d) 是为了避免维度变大后分数过猛，softmax 过早变得尖锐。

scores = torch.bmm(queries, keys.transpose(1, 2)) / math.sqrt(d)
attention_weights = masked_softmax(scores, valid_lens)
output = torch.bmm(attention_weights, values)

形状怎么走

张量典型形状含义
queriesB × query_len × H当前位置拿什么去问
keysB × key_len × H所有可被看的位置
valuesB × key_len × H真正要被加权求和的信息
weightsB × query_len × key_len每个 query 看每个 key 的比例
在 encoder self-attention 里，Q、K、V 都来自同一个 X；在 decoder cross-attention 里，Q 来自 decoder，K 和 V 来自 encoder outputs。

3Multi-Head：把一次注意力拆成多种视角

MultiHeadAttention

单头注意力只在一个表示空间里匹配。多头注意力先用 W_q/W_k/W_v 投影，再把隐藏维度 H 切成 h 份，让不同头分别学不同关系：有的头可能看主谓关系，有的头可能看相邻词，有的头可能看标点或句尾。

queries = transpose_qkv(self.W_q(queries), self.num_heads)
keys = transpose_qkv(self.W_k(keys), self.num_heads)
values = transpose_qkv(self.W_v(values), self.num_heads)
output = self.attention(queries, keys, values, valid_lens)
return self.W_o(transpose_output(output, self.num_heads))

这里的两个 transpose

1
transpose_qkv

把 B × L × H 变成 (B × h) × L × (H/h)。这样可以把每个 head 当成一个更大的 batch 来并行计算。

2
transpose_output

多头算完以后，再把 (B × h) 合回 B，把多个头的结果拼回完整 H。

4位置编码：给无序注意力补上顺序感

PositionalEncoding

self-attention 本身不天然知道 token 的先后顺序。如果只把词向量送进去，“我 赢 了”和“了 赢 我”在集合意义上很像。位置编码把每个位置的 sin/cos 向量加到 embedding 上，让模型知道“这个 token 在第几个位置”。

X = embedding(tokens) * math.sqrt(num_hiddens)
X = pos_encoding(X)

为什么乘 sqrt(H)

位置编码的值大约在 -1 到 1 之间。embedding 训练初期数值尺度可能较小，乘上 sqrt(H) 后，词语信息不会被位置编码淹没。这是教材 Transformer 代码里的经典写法。

5FFN 与 AddNorm：让网络能堆深

PositionWiseFFN

注意力负责“位置之间交流”，FFN 负责“每个位置自己消化信息”。它对每个 token 位置使用同一个两层 MLP，通常先升维再降回 H。本代码里是 H → 64 → H。

class PositionWiseFFN(nn.Module):
    def forward(self, X):
        return self.dense2(self.relu(self.dense1(X)))

AddNorm

每个子层外面都有残差连接和 LayerNorm。残差让原始信息可以直接穿过子层，LayerNorm 把每个位置的特征尺度拉稳。没有它们，深层 Transformer 很容易训练不稳。

def forward(self, X, Y):
    return self.ln(self.dropout(Y) + X)

6EncoderBlock：读完整源句

encoder block
输入形状 B × 6 × H
输出形状 B × 6 × H
并行头数 4

代码对应关系

def forward(self, X, valid_lens):
    Y = self.addnorm1(
        X, self.attention(X, X, X, valid_lens))
    return self.addnorm2(Y, self.ffn(Y))

这一块只做 self-attention，所以 Q、K、V 都是 X。输出形状仍是 B × S × H，但每个位置已经混入了整句上下文。堆叠多层以后，encoder 返回的就是 decoder 要反复读取的 enc_outputs。

7DecoderBlock：一边生成，一边回看源句

三个子层

1
masked self-attention

目标端内部交流，但只能看当前位置及以前的目标 token，不能偷看未来答案。

2
encoder-decoder attention

decoder 当前表示作为 query，encoder outputs 作为 key/value，决定当前要翻译时应该看源句哪里。

3
FFN + AddNorm

每个位置独立处理，再保持形状不变地交给下一层或输出层。

decoder data flow
cross-attn 读取 encoder memory
缓存层数 2
def forward(self, X, state):
    enc_outputs, enc_valid_lens, cache = state
    key_values = X if cache[self.i] is None else torch.cat((cache[self.i], X), dim=1)
    cache[self.i] = key_values
    X2 = self.attention1(X, key_values, key_values, dec_valid_lens)
    Y = self.addnorm1(X, X2)
    Y2 = self.attention2(Y, enc_outputs, enc_outputs, enc_valid_lens)
    Z = self.addnorm2(Y, Y2)
    return self.addnorm3(Z, self.ffn(Z)), state

8训练和预测：同一个 decoder，两种用法

训练：teacher forcing

训练时目标句已知，所以 decoder 输入是 <bos> + Y[:-1]，标签是完整的 Y。模型一次性预测每个位置，下三角 mask 保证第 t 位不能看到答案的未来部分。

bos = torch.full((Y.shape[0], 1), tgt_vocab["<bos>"])
dec_X = torch.cat([bos, Y[:, :-1]], 1)
Y_hat, _ = net(X, dec_X, Xvl)
l = loss(Y_hat, Y, Yvl)

预测：自回归生成

预测时没有真实目标句。decoder 从 <bos> 开始，每次拿最后一个位置的 logits 选出下一个 token，再把它接回 decoder 输入，直到生成 <eos>。

dec_X = torch.tensor([[tgt_vocab["<bos>"]]])
Y, state = net.decoder(dec_X, state)
dec_X = Y[:, -1:].argmax(dim=2)
