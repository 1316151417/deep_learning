Transformer：按课程原版结构手写

这个版本不再包一层 PyTorch 的 nn.Transformer。它按照课程里的拆法，把通用组件自己写出来：多头注意力、AddNorm、PositionWiseFFN、EncoderBlock、DecoderBlock、Encoder、Decoder。也就是说，结构更接近教材原文，只是把教材里依赖的 d2l 模块替换成了本文件里的实现。

和 27_attention_seq2seq 相比，最大变化不是“加了注意力”，而是把 RNN 时间循环替换成注意力块堆叠：编码器一次性看完整源序列，解码器用 causal mask 保持自回归。

1课程组件对应代码

class EncoderBlock(nn.Module):
    def forward(self, X, valid_lens):
        Y = self.addnorm1(
            X, self.attention(X, X, X, valid_lens))
        return self.addnorm2(Y, self.ffn(Y))
class DecoderBlock(nn.Module):
    def forward(self, X, state):
        X2 = self.attention1(X, key_values, key_values, dec_valid_lens)
        Y = self.addnorm1(X, X2)
        Y2 = self.attention2(Y, enc_outputs, enc_outputs, enc_valid_lens)
        Z = self.addnorm2(Y, Y2)
        return self.addnorm3(Z, self.ffn(Z)), state
教材里的 d2l.MultiHeadAttention、d2l.PositionalEncoding、d2l.EncoderDecoder 在这里都由本文件自实现；训练数据、mask loss、BLEU 复用前面章节已有的小工具。

2拖动看 EncoderBlock

encoder block

EncoderBlock 不改变形状。每层先做多头自注意力，让每个源 token 看到其它源 token；再做逐位置前馈网络。两段外面都包 Add & Norm。

输入形状 B × 6 × H
输出形状 B × 6 × H
并行头数 4

causal self-attention

训练时 decoder 一次拿到整条目标序列，但第 t 行只能看 0..t。预测时缓存已经生成的 key/value，逐步追加。

decoder data flow
