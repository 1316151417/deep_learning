GPT-1：从生成式预训练到任务微调

这页把 zj_test/py/30_gpt1/ 这套实现拆开讲。GPT-1 的核心不是某个新结构，而是一个范式：先用无监督语言模型在海量文本上预训练，再在下游任务上微调——并且微调时还保留一个语言模型辅助目标。我们会逐块对照代码，看每一段在干什么、张量形状怎么变、以及它和第 29 讲的 encoder-decoder Transformer 差在哪。

阶段一 · 预训练

只有输入序列、没有标签。模型预测「下一个词」，学会语言的通用统计规律。对应 train.pretrain()。

阶段二 · 微调

接上一个小任务头，用带标签数据训练。关键是不丢掉语言能力——加一个辅助 LM 损失。对应 train.finetune()。

为什么有效

预训练把词法、句法、常识编码进权重；微调只需少量标注就能把这些能力「对齐」到具体任务。

和第 29 讲的翻译 Transformer 相比，GPT 砍掉了 encoder 和 cross-attention，只留 decoder（因果自注意力）。一套结构、两个用法：预训练时输出整句的词概率，微调时在末尾取一个位置的向量送进任务头。

代码对应关系

# model.py : GPTModel
self.wte = nn.Embedding(vocab_size, n_embd)   # token 嵌入
self.wpe = nn.Embedding(n_ctx, n_embd)        # 学习的位置嵌入
self.blocks = nn.ModuleList([Block(cfg) for _ in range(n_layer)])
self.ln_f = nn.LayerNorm(n_embd)

def forward(self, idx):
    pos = torch.arange(T)
    x = self.drop(self.wte(idx) + self.wpe(pos))  # 不乘 sqrt(d)
    for block in self.blocks: x = block(x)
    return self.ln_f(x)                 # B × T × n_embd

末尾的 ln_f 是 Pre-LN 风格必须的「最终归一化」。语言模型头 LMHead 与 wte 权重绑定：logits = hidden @ wte.weight.T。

Pre-LN（不是 Post-LN）
每个 Block 是 x = x + attn(ln_1(x)) 再 x = x + ffn(ln_2(x))——LayerNorm 在子层之前。这是 GPT 官方实现的选择，和原始 Transformer 的 Post-LN 不同，训练更稳。
四个反「Attention is All You Need」的细节
① 学习的位置编码（非正弦）；② GELU（非 ReLU）；③ token 嵌入不乘 sqrt(d)；④ LM 头与嵌入权重绑定。代码里逐条对齐了 OpenAI 的 finetune-transformer-lm。

2因果自注意力：让未来词失声

CausalSelfAttention

GPT 是单向的：预测第 t 个词时，只能看 0..t，不能偷看 t+1..。实现上对注意力分数矩阵施加一个下三角掩码——上三角位置填 -inf，softmax 后概率为 0。

# model.py : CausalSelfAttention
att = (q @ k.transpose(-2,-1)) / sqrt(head_dim)
att = att.masked_fill(mask[:,:,:T,:T] == 0, -inf)
att = softmax(att, dim=-1)
y = att @ v

qkv 用一个线性层一次性投影成 q、k、v，再 split。多头靠把 n_embd 沿最后一维切成 n_head 份实现，所以 n_embd 必须能被 n_head 整除。

无监督语言模型损失

把整段语料切成定长窗口。输入 x 是一段 token，标签 y 是 x 右移一位——也就是让位置 t 去预测 token t+1。整条序列每个位置都贡献一个交叉熵，加起来平均。

# train.py : pretrain
x, y = lm_batch(token_ids, block_size, ...)
logits = model(x)                       # B × T × V
loss = F.cross_entropy(
    logits.reshape(-1, V), y.reshape(-1))
loss.backward(); opt.step()
实测在内置小语料上预训练 8 个 epoch，LM 损失从 ≈5.7 降到 ≈0.05——模型几乎背下了这小段语料，所以续写能复现「the cat sat on the mat」。真实复现用 BooksCorpus 时损失远高于此，但学到的语言知识可迁移。

优化器配方对齐论文：Adam（预训练 β2=0.98、ε=1e-9），学习率线性 warmup 后余弦衰减到 0，梯度范数裁剪 1.0。

4微调 + 辅助 LM 目标：L3 = L2 + λ·L1

双损失合并（拖 λ 看权重）
λ = 0.50
总损失 = L2 + 0.50·L1

GPT-1 的关键一手

微调时只用分类损失 L2 会让模型「忘掉」语言能力。论文的做法是把语言模型当作辅助目标，和任务损失一起优化，λ=0.5：

# train.py : finetune
hidden = model.hidden_states(x)
l2 = CE(classifier(hidden, extract_pos), labels)  # 任务损失
lm_logits = model.lm_head(hidden)
l1 = lm_loss(lm_logits, x, valid)              # 仅真实位置
loss = l2 + lm_weight * l1                  # λ = 0.5
辅助项在padding 之外的真实 token 位置上计算，避免 padding 干扰。λ=0 退化为纯监督微调；λ 越大越像继续做语言模型——保持泛化、加速收敛。

6BPE 分词器：把词切成子词






为什么要 BPE


GPT-1 用字节对编码（BPE）做子词分词：高频整体成词，低频拆成更小单元。好处是词表小、又能处理任何没见过的词（按字符回退）。tokenizer.py 里是自包含实现：先按空格切词并加词尾标记 </w>，再反复合并出现最多的相邻符号对。


# 训练：合并最高频相邻对
best = max(pairs, key=pairs.get)
vocab = merge_word(best, vocab)

# 编码：对每个词按「合并优先级」贪心合并
best = min(pairs, key=lambda p: bpe_ranks.get(p, inf))
