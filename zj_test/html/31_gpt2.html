GPT-2：无监督多任务，零样本就够了

这页把 zj_test/py/31_gpt2/ 这套实现拆开讲。GPT-2 相对 GPT-1 的核心转变不是堆参数，而是砍掉微调：一个纯语言模型，把任何任务都写成「文本续写」，靠提示词零样本完成。配套的两个工程变化是 字节级 BPE（永远没有 OOV）和把架构/初始化微调成更耐深的 Pre-LN。我们会逐块对照代码，看每一处在干什么、和 GPT-1 差在哪。

GPT-1：两阶段

预训练 → 每个任务再微调 + 任务头 + 辅助 LM 损失。换一个任务就要重训一次头。

GPT-2：一阶段

只预训练。没有任务头、没有微调。任务靠把输入拼成自然语言提示，让模型「接着写」。

为什么能

WebText 里本就含翻译、问答、摘要的文本。模型在学「续写」时，顺带学会了「按格式续写 = 完成任务」。

这套「无监督多任务学习」(unsupervised multitask learner) 的赌注是：只要数据和模型够大，语言建模本身就会涌现出任务能力——不需要为每个任务标注、也不需要专门的头。代价是对规模极其敏感，所以 GPT-2 同时把模型做到 1.5B、上下文拉到 1024。

1字节级 BPE：永远没有 OOV

GPT-1 字符 BPE → GPT-2 字节 BPE

GPT-1 的 BPE 以字符为基底，词表随语料变化，遇到训练时没见过的字符（如 é、汉字）就直接 KeyError。GPT-2 改成以256 个字节为基底：任何文本先编码成 UTF-8 字节，再把每个字节映射成一个可见 Unicode 字符（其中空格 → Ġ），最后在这层字符上做 BPE 合并。

# tokenizer.py : bytes_to_unicode (OpenAI 标准)
bs = range(ord('!'),ord('~')+1) + ...        # 可见字节保持自身
for b in range(256):
    if b not in bs:                   # 不可见字节 → 256 之后
        cs.append(256+n); n += 1             # 空格 0x20 → 'Ġ' U+0120

# encode: 正则切分 → UTF-8 字节 → 字节字符 → BPE
byte_str = "".join(byte_encoder[b] for b in chunk.encode("utf-8"))
输入任意文本（汉字、emoji、二进制噪声都行），点「编码」看它如何层层转换。注意空格怎么变成 Ġ，以及无论输入多怪都不会失败。

代码对应关系

# model.py : GPTModel
self.wte = nn.Embedding(vocab_size, n_embd)   # 字节级词表
self.wpe = nn.Embedding(n_ctx, n_embd)        # n_ctx = 1024
self.h = nn.ModuleList([Block(cfg) for _ in range(n_layer)])
self.ln_f = nn.LayerNorm(n_embd)             # Pre-LN 必须的末层归一化

def forward(self, idx):
    x = self.drop(self.wte(idx) + self.wpe(pos))
    for block in self.h: x = block(x)
    return self.ln_f(x)                 # B × T × n_embd

和 GPT-1 一样是 decoder-only、权重绑定 logits = hidden @ wte.T。但 LayerNorm 的位置反过来了——见下面两块。

Pre-LN（GPT-2）vs Post-LN（GPT-1）
GPT-2 的 Block：x = x + attn(ln_1(x))——LayerNorm 在子层之前，残差主路径是恒等映射，深层梯度更稳，所以需要在堆叠末尾补一层 ln_f。GPT-1 的官方实现是 Post-LN ln(x+attn(x))，不需要 ln_f。
GPT-2 才有的三个细节
① tanh 近似 GELU（非 erf，匹配官方权重）；② 上下文 1024（GPT-1 是 512）；③ 残差输出投影初始化缩放 1/√N（下一节）。命名也换成 c_attn / c_proj / c_fc。

3残差缩放初始化：1/√N

哪些权重被缩小（拖层数看系数）
残差子层数 N 24
缩放系数 1/√N 0.204
c_proj 初始化 std 0.0041

为什么缩小残差层权重

Pre-LN 下残差流不断累加子层输出，深层容易方差爆炸。论文用「残差层初始化缩放 1/√N」缓解：把每个残差子层的输出投影（注意力的 c_proj、FFN 的 c_proj）权重额外除以 √N，使初始时网络近似恒等映射。N = 残差子层数 = 2·n_layer。

# model.py : GPTModel.__init__
self.apply(self._init_weights)          # 先全部 N(0, 0.02)
for name, param in self.named_parameters():
    if name.endswith("c_proj.weight"):   # 只缩放残差输出投影
        nn.init.normal_(param, std=0.02/math.sqrt(2*n_layer))
对比：GPT-1 的 _init_weights 对所有 Linear 一视同仁用 0.02，没有这步缩放。注意 c_attn（QKV）、c_fc（FFN 内层）、embedding 都不被缩放——只有输出加回残差流的那两层被缩。

4训练目标与困惑度 PPL

pretrain loss 与困惑度（实测曲线）
初始损失 ≈ 6.21−ln(1/500 词表)
收敛损失 ≈ 0.08
验证 PPL ≈ 1.08exp(loss)

目标不变，指标换了

训练目标还是无监督语言模型（和 GPT-1 的 L1 一样）：输入右移一位当标签。但 GPT-2 不再有微调阶段，主评估指标从「分类准确率」换成困惑度 PPL = exp(平均 token 负对数似然)——越低代表模型对下一个 token 越「确定」。

# train.py : pretrain
x, y = lm_batch(token_ids, block_size, ...)
loss = F.cross_entropy(model(x).reshape(-1,V), y.reshape(-1))

# train.py : perplexity
ppl = math.exp(nll_sum / n_tokens)
优化器配方对齐 GPT-2：Adam（β2=0.999、ε=1e-8，GPT-1 是 0.98）+ 权重衰减 0.01（LayerNorm/bias 不衰减），线性 warmup 后余弦衰减，梯度裁剪 1.0。
